#### P0-1 详细说明：CI 安全扫描强制阻断构建

**问题**: `security-scan` 任务设置了 `continue-on-error: true`，高危漏洞可被忽略部署到生产环境。

**修改步骤**:
1. 移除 `.github/workflows/ci.yml` 中 `security-scan` 的 `continue-on-error: true`
2. 移除 `npm audit` 的 `continue-on-error: true`
3. 将 `security-scan` 加入 `build` 任务的 `needs` 依赖
4. 更新 `build` 任务的 `if` 条件，要求安全扫描通过

**验证标准**: 提交一个带已知漏洞的依赖版本，确认 CI 构建失败。

#### P1-4 详细说明：前端性能优化

**当前 Lighthouse 预估评分**:
- Performance: ~60-70
- Accessibility: ~85
- Best Practices: ~90
- SEO: ~80

**优化方向**:
1. **图片优化**: 将 `public/images/` 下的 PNG 转为 WebP，添加响应式 `srcset`
2. **代码分割**: 路由级别懒加载 (`const Home = () => import('./views/Home.vue')`)
3. **CSS 优化**: 提取关键 CSS，异步加载非关键样式
4. **Tree Shaking**: 检查 `lodash` 等库是否使用全量导入
5. **Gzip/Brotli**: 配合 P1-2 的响应压缩

   ```typescript
    *     tags: [Members]
    *     parameters:
    *       - in: query
    *         name: status
    *         schema:
    *           type: string
    *           enum: [active, inactive]
    *     responses:
    *       200:
    *         description: 成员列表
    */
   ```
