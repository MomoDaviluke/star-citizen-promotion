# 系统性技术栈重构与优化 实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 将 Star Citizen 战队宣传网站从"功能完成但含技术债"状态，通过风险分级递进重构，推进到"代码精简、测试闭环、规范统一、指标可量化"的可维护状态。

**架构：** 方案 A — 风险分级递进。5 阶段（P1 基线 / P2 清理 / P3 统一 / P4 重构 / P5 验收），每阶段独立分支可回滚，P4 高风险项按 TD 切子分支。基线分支 `main`（HEAD `4023768`），集成分支 `refactor/systematic-cleanup`。

**技术栈：** Vue 3 + Vite + Pinia + GSAP（前端）| Express + TypeScript + MySQL + Knex（后端）| Vitest + Jest + Playwright（测试）| ESLint + Prettier（规范）

**规格说明：** [docs/superpowers/specs/2026-06-25-refactor-design.md](../specs/2026-06-25-refactor-design.md)

```typescript
    [...params, id]
  )
```

```javascript
/**
```

```typescript
 * @description 按 RFC 5545 规范转义 ICS 属性值中的特殊字符

/**
 * 转义 ICS 文本中的特殊字符
 * @description 按 RFC 5545 规范，转义分号、逗号、反斜杠、换行符
 * @param text - 待转义的文本
 * @returns 转义后的文本
 */
export function escapeIcsText(text: string): string {
  if (!text) return ''
  return text
    .replace(/\\/g, '\\\\')  // 反斜杠必须先转义，避免影响后续转义
    .replace(/;/g, '\\;')
    .replace(/,/g, '\\,')
    .replace(/\n/g, '\\n')
}
```

```typescript
  const lines = [
    'BEGIN:VCALENDAR',
    'VERSION:2.0',

    event.location ? `LOCATION:${escapeIcsText(event.location)}` : '',
    'END:VEVENT',

  ].filter(Boolean)
```
